# Contributing

Small, verifiable changes are welcome. State accuracy comes before extra animations.

1. Fork the repository and use Node.js 22+.
2. Run `npm install`, `npm test`, and `npm run check`.
3. For behavior changes, add an event sequence test covering the failure and recovery. Use synthetic IDs and folder names.
4. Run `npm run test:ui` for desktop changes. Attach a screenshot for UI or theme work; test reduced motion and both languages.
5. Explain the user-visible change, validation, and limitations in the pull request.

Never submit API keys, private prompts, transcript files, actual Claude settings, or confidential results. Themes need an author and a license compatible with MIT; do not submit assets copied from games. Read [THEMES.md](docs/THEMES.md).

Use respectful, specific feedback. Harassment and discriminatory conduct are not welcome. By contributing, you agree that your contributions may be distributed under the project's MIT license.
