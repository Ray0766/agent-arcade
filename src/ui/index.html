Connect your workshop

One WeChat owner, one local project, one Claude agent. Your computer must stay on.

On your phone, open WeChat → Me → Settings → Plugins → ClawBot, enable it, then scan below. Send tasks in the ClawBot conversation, not to an ordinary contact named Agent Arcade. If this entry is missing, client compatibility or account availability remains unverified.

Enable ClawBot in mobile WeChat, then scan and confirm. Codes expire after three minutes.

In-flight requests may exceed this threshold. It is not a hard billing cap.

Uses the original Claude Code CLI and its existing login. Agent Arcade does not read Claude credentials. Requires Node.js 22.13+ and local Claude Code 2.1.317. After connecting, run the command below yourself, confirm the custom Channels research preview in the terminal, and keep it open. The CLI follows its existing permissions; already allowed tools may run automatically.

Stop Claude locally with Ctrl+C. WeChat /cancel and Disconnect only stop forwarding; they cannot guarantee that Claude stops.

Your saved API key stays stored when switching modes.

Chat commands & permissions
Send a task in plain language. /status checks progress; /cancel stops the task and clears the queue; /new starts fresh. Tool actions ask for a one-time /allow code or /deny code. Questions accept /answer code text.
An approved command can affect your computer beyond the selected folder. A reply ending does not prove the work succeeded. Disconnection cancels active work; tasks are never resumed automatically.
